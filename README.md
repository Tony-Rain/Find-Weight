## Нахождение вектора весов по данным
Данный проект написан в рамках изучения основ machine learning.
Реализовано нахождение вектора весов по данным.
Также написан генератор искусственных данных с добавлением шума 
по случайному вектору весов.
Для более удобной работы и более глубокого понимания реализован класс
матриц и подкласс векторов с базовыми операциями над ними (в том числе и арифметическими).
